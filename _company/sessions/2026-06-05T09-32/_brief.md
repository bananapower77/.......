# 📋 작업 브리프

**원 명령:** 발로란트 내전 통계 대시보드를 만들고 싶어 
이미지나 리플레이 영상을 제출하면 ai가 kda와 승률 요원 픽률을 자동 분석해주고 누가 mvp플레이어인지
누가 가장 좋은 듀오인지 내전할때 팀도 실력에 맞춰 짜주는 그런 프로그램이나 웹사이트를 만들고 싶어
웹사이트가 안되면 파일로 만들어줘도 될거야

## 요약
발로란트 내전 영상 분석 프로그램/웹사이트 제작 요청입니다. 이미지 또는 리플레이 영상을 입력하면 AI가 KDA, 승률, 요원 픽률 등을 자동으로 분석하여 MVP 플레이어 및 가장 좋은 듀오를 파악합니다. 웹사이트 형식이 가능하며 불가능 시 파일 형식으로 제출도 허용됩니다.

## 분배
- **📺 레오**: 게임 통계/데이터 분석, 리플레이 영상 데이터 수집 관련 트렌드 및 경쟁 사례 조사
- **💻 코다리**: 이미지/리플레이 영상 분석 기능 개발 (AI 모델 연동 포함), 프로그램/웹사이트 구축. 파일 형식 제출 방안 모색
- **🎨 Designer**: 프로그램/웹사이트 디자인 브리프 작성: 사용자 친화적 인터페이스, 데이터 시각화 전략 등.
- **💼 현빈**: 수익 모델 분석: 구독형, 광고, 프로모션 상품 등 다양한 수익 방안 고려 및 비교 분석
- **🔍 Researcher**: 발로란트 내전 관련 데이터 시나리오 생성 (MVP 플레이어 탐지 기준, 듀오 분석 방법 등)
